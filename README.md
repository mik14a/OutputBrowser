# Output Browser 📱

OutputBrowserは、画像ファイルの出力を監視・閲覧するための専用ビューアです。
複数の監視対象を設定し、Discord風のチャンネル形式で新しい出力を確認できます。

## 最新アップデート (2026/10/13) 🎉

### 新機能
- 画像を開くビューアーを、内蔵ビューアーと外部ビューアーから選べるようになりました 🖼️
  - 既定は内蔵ビューアーです
  - 外部ビューアーを選ぶと、Windows の既定のアプリで開きます
- 内蔵ビューアーで、表示中チャンネルの前後の画像へ移動できます ⬅️➡️
  - 左右のボタン、または ← / J で前へ、→ / K で次へ
  - 右クリックの「前後の画像」で、左右のボタンを隠せます
- 内蔵ビューアーの右クリックから、一覧と同じ操作ができます 🖱️
  - 開く、画像フォルダを開く、ファイルをコピー、画像をコピー、パスのコピー、プロンプトのコピー
  - 「プロンプトの表示」で、画像の下に生成情報を出せます
- 一覧が末尾にあるときは、新しい出力が来ると自動で末尾へスクロールします 📜
  - 末尾以外にいるときはスクロールせず、生成された画像を見られます
- 内蔵ビューアーは、表示中の画像が末尾のときだけ新しい出力へ切り替わります 🔄
  - 一覧が末尾のまま更新されていても、末尾以外の画像を個別に見ているあいだは表示を切り替えません
  - ウィンドウをまだ開いていないときは、勝手には開きません

## セットアップ 🚀

### 監視設定 ⚙️
1. 左下の設定アイコンから監視設定画面を開く
2. 「新規監視」ボタンで監視グループを作成
3. 以下の項目を設定:
   - アイコン: 通知者のアバター（誰からの通知かを視覚的に区別）
   - 名前: 通知者の表示名
   - パス: 監視するフォルダのパス
   - フィルタ: 監視対象のファイル形式 (例: \*.png;\*.jpg;\*.jpeg)
   - メッセージ形式: 出力メッセージのカスタマイズ
     - {{name}}: ファイル名
     - {{path}}: 相対パス
     - 空の場合は相対パスを表示する
     > 例: "ʕ๑•ᴥ•๑ʔ < わぁい！{{name}}できたよ！"
   - 通知: ファイル更新時に通知する

### アプリケーション設定 🎨
- テーマ設定: システム / ライト / ダーク 🌓
- 背景エフェクト: マイカ / マイカオルタナティブ / アクリル / アクリル(カスタム) ✨
- ビューアー: 内蔵ビューアー / 外部ビューアー 🖼️
  - ファイル名のリンクや「開く」は、ここで選んだビューアーを使う
- デフォルトの監視フォルダとフィルタの設定 📌
- ウィンドウの常に最前面表示設定 📌
  - タイトルバー中央のアプリアイコンで切り替える
- 「保存」を押すと、設定を開く前に見ていたページへ戻る ↩️

### 画像の操作 🖱️
一覧の画像を右クリックすると:
- 開く 📂
  - 設定が内蔵ビューアーなら専用ウィンドウで開く
  - 設定が外部ビューアーなら Windows の既定のアプリで開く
- 画像フォルダを開く 🗂️
- ファイルをコピー 📋
- 画像をコピー 🖼️
- パスのコピー 📝
- プロンプトのコピー（AI生成画像用）✨
- プロンプトの表示 👁️

内蔵ビューアーでは、画像の上で右クリックすると同じ操作に加えて:
- プロンプトの表示: 画像の下へ生成情報を重ねる
- 前後の画像: 左右の移動ボタンを出す / 隠す

内蔵ビューアーでの移動:
- 左のボタン、← 、J 、ホイールを上 : 一つ前の画像
- 右のボタン、→ 、K 、ホイールを下 : 一つ次の画像
- 移動できる画像は、いま開いているチャンネルの一覧です

## 便利な機能 💡

- 自動スクロール: 一覧が末尾にあるとき、新しい画像が追加されると自動的に末尾へスクロール 📜
  - 末尾以外にいるときは自動スクロールを止め、生成された画像を見られる
  - そのあいだは末尾へのジャンプボタンを表示
  - スペースキーでも末尾へ移動できる
- 内蔵ビューアーの追従 🔄
  - 表示中の画像が末尾のときだけ、開いている内蔵ビューアーを最新の出力へ切り替える
  - 一覧が末尾のまま更新されていても、末尾以外の画像を個別に見ているあいだは表示を切り替えない
- プロンプト管理 📝
  - AI生成画像のプロンプト情報を保持
  - PNG の埋め込みテキストを順に探す（Automatic1111 の parameters、ComfyUI の prompt / workflow。圧縮された zTXt も含む）
  - ワンクリックでプロンプトをコピー
  - 一覧と内蔵ビューアーのそれぞれで、プロンプトの表示 / 非表示を切り替えられる

## 活用例 💫

### AI画像生成との相性抜群 🎨
- ローカルで動作するAI画像生成モデルの出力フォルダを監視 🤖
  - Stable Diffusion WebUI
  - NovelAI
  - ComfyUI
など、ローカルで画像を生成するモデルの出力をリアルタイムに確認できます

例えば:
画像生成グループ「AI工房」を作成し:
- 「SD-ちゃん🎨」(アバター: SDのロゴ) でStable Diffusion WebUIの出力を監視
- 「NAI-にゃん✨」(アバター: NovelAIのロゴ) でNovelAIの出力を監視
- 「Comfy-くん🔧」(アバター: ComfyUIのロゴ) でComfyUIの出力を監視
など、モデルごとに可愛らしい通知者を設定し、グループで管理できます。

生成が続いているあいだ、一覧が末尾なら新しい画像へ自動でスクロールします。末尾以外では、その位置のまま生成された画像を見られます。内蔵ビューアーは、末尾の画像を開いているときだけ新しい画像へ追従します。一覧が末尾で更新されていても、末尾以外の画像を開いているあいだは、その詳細のまま見られます。前後は ← / → 、J / K 、マウスホイールで動けます。
